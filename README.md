# مدير مزرعة المجدول

تطبيق سطح مكتب عربي لإدارة عمليات المزرعة، يعمل محليًا على Windows باستخدام PySide6 وSQLite. يدعم التطبيق إدارة هيكل المزرعة، الإنتاج الزراعي، المخزون، المشتريات، المبيعات، الموارد البشرية، الأصول والتقارير من واجهة عربية RTL.

## الحالة الحالية

المشروع في مرحلة MVP متقدمة وقابل للتشغيل المحلي. يحتوي على طبقات منفصلة للواجهة والخدمات والمستودعات وقاعدة البيانات، مع اختبارات للوحدات والتكامل وفتح شاشات الواجهة.

الوظائف المنفذة حاليًا:

- لوحة تحكم تشغيلية ومؤشرات أساسية.
- إدارة المزارع والقطاعات والبلوكات في هيكل هرمي.
- حفظ مساحة المزرعة والبلوك وعدد النخيل والملاحظات.
- إدارة المواسم ودفعات الحصاد والفرز والتعبئة.
- إدارة المخازن والأصناف والأرصدة وحركات الصرف والاستلام.
- دورة المشتريات: مورد، فاتورة، بنود، تأكيد، استلام مخزني، وسداد.
- دورة المبيعات: عميل، فاتورة، بنود، تأكيد، تحصيل، وكشف حساب.
- محرر فواتير متعدد البنود مع حساب تلقائي للإجماليات.
- تعديل مسودات الفواتير وحذف البنود والمسودات وإلغاء الفواتير المؤكدة حسب قواعد السلامة.
- إدارة الموظفين والحضور والرواتب والسلف.
- إدارة الأصول وأوامر الصيانة.
- إدارة الاستشاريين والزيارات والتقارير.
- واجهة عربية RTL وثيم موحد وبحث وجداول ولوحات تفاصيل.
- نسخ احتياطي واسترجاع لقاعدة SQLite عبر أدوات البنية التحتية.

## المتطلبات

- Windows 10 أو Windows 11.
- Python 3.11 أو أحدث.
- اتصال بالإنترنت مطلوب فقط لتثبيت الاعتمادات، وليس لتشغيل التطبيق.

الاعتمادات الرئيسية:

- PySide6 6.7 أو أحدث وأقل من 7.
- SQLAlchemy 2 أو أحدث وأقل من 3.
- pytest 8 للاختبارات.

## التثبيت والتشغيل

من داخل مجلد المشروع:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m app
```

أو مباشرة باستخدام Python المثبت:

```powershell
py -m pip install -r requirements.txt
py -m app
```

## الاختبارات والتحقق

```powershell
py -m pytest -q
py -m pytest -q tests/test_ui_smoke.py
py -m compileall -q app
```

اختبارات المشروع تستخدم قاعدة SQLite مؤقتة معزولة عن قاعدة بيانات المستخدم. لا تشغّل اختبارات التكامل على قاعدة البيانات التشغيلية يدويًا.

## مكان بيانات التطبيق

تُحفظ قاعدة البيانات المحلية افتراضيًا في:

```text
%LOCALAPPDATA%\MedjoolFarmManager\medjool_farm.db
```

يمكن تغيير مجلد البيانات باستخدام متغير البيئة `MEDJOOL_APP_DIR`:

```powershell
$env:MEDJOOL_APP_DIR = "D:\MedjoolData"
py -m app
```

لا تحذف ملف قاعدة البيانات قبل أخذ نسخة احتياطية.

## دورة العمل الأساسية

### إعداد هيكل المزرعة

1. افتح «هيكل المزرعة».
2. أضف مزرعة وسجل الموقع والمساحة.
3. حدد المزرعة من الشجرة وأضف قطاعًا.
4. حدد القطاع وأضف بلوكًا مع الكود والمساحة وعدد النخيل.

يجب تحديد العنصر الأب صراحة عند إضافة قطاع أو بلوك.

### المشتريات والمخزون

1. أضف المورد.
2. اضغط «فاتورة شراء جديدة».
3. اختر المورد والتاريخ.
4. أضف بندًا أو عدة بنود داخل محرر الفاتورة.
5. راجع الإجمالي ثم احفظ المسودة.
6. أكد الفاتورة لاستلام الأصناف إلى المخزن.
7. نفذ السداد من الفاتورة المؤكدة.

الفاتورة المؤكدة تنشئ حركات مخزون، لذلك لا يمكن حذفها أو تعديل بنودها. يمكن حذف المسودة أو تعديلها.

### المبيعات والتحصيل

1. أضف العميل.
2. اضغط «فاتورة بيع جديدة».
3. اختر العميل والتاريخ والخصم والضريبة.
4. اختر دفعة حصاد ذات رصيد متاح.
5. أضف البنود وراجع الكميات والأسعار والإجمالي.
6. احفظ الفاتورة ثم أكدها.
7. أضف التحصيل على الفاتورة المؤكدة.

الفاتورة المؤكدة تخصم من رصيد دفعات الحصاد. إلغاؤها يتم بحركة عكسية، ولا تُحذف من السجل.

## بنية المشروع

```text
app/
	domain/          نماذج SQLAlchemy ومفاهيم المجال
	application/     قواعد الحساب وخدمات التطبيق
	infrastructure/  المستودعات وقاعدة البيانات والتخزين
	database/        إعداد محرك SQLite والجلسات
	presentation/    صفحات PySide6 والثيم والقالب الرئيسي
tests/             اختبارات الوحدات والتكامل والواجهة
.github/           تعليمات الوكلاء وملفات CI والإصدارات
```

قاعدة الفصل الأساسية:

```text
واجهة المستخدم -> خدمة التطبيق -> المستودع -> قاعدة البيانات
```

لا تضف عمليات كتابة مباشرة إلى SQLite من صفحات الواجهة. استخدم الخدمات والمستودعات حتى تبقى قواعد المخزون والفواتير والرواتب قابلة للاختبار.

## سلامة البيانات

- SQLite Foreign Keys مفعلة.
- وضع WAL مفعّل للتشغيل المحلي.
- المعاملات تمنع حالات السباق في عمليات الفحص ثم الكتابة.
- لا يسمح بصرف مخزون أو بيع كمية أكبر من الرصيد.
- لا يسمح بتحصيل أو سداد يتجاوز الرصيد.
- لا يسمح بتعديل الفاتورة المؤكدة.
- حذف الكيانات المرتبطة بسجلات تشغيلية محمي برسائل واضحة.
- إلغاء البيع المؤكد يحفظ الحركة الأصلية وينشئ حركة عكسية بدل الحذف الصامت.

## النسخ الاحتياطي

1. أغلق التطبيق.
2. انسخ ملف `medjool_farm.db` إلى وسيط آمن.
3. احتفظ بأكثر من نسخة بتاريخ واضح.
4. اختبر الاسترجاع على نسخة منفصلة.

توجد دوال `backup_database` و`restore_database` في `app/database/db.py` لاستخدامها عند بناء شاشة النسخ الاحتياطي النهائية.

## خارطة الطريق

1. إغلاق اختبارات الواجهة وإضافة اختبارات لمسارات إنشاء وتعديل وحذف الفواتير.
2. إضافة النسخ الاحتياطي والاسترجاع من الواجهة مع سجل عمليات.
3. إضافة صلاحيات المستخدمين وسجل التدقيق.
4. استكمال التحويلات والجرد والتسويات المخزنية.
5. تطوير تكلفة الموسم والبلوك وتكلفة الكيلو.
6. إضافة تصدير PDF وExcel وطباعة الفواتير.
7. تجهيز مثبت Windows ودليل المستخدم.

## ملاحظات مهمة

- التطبيق محلي ولا يحتاج إلى إنترنت أثناء التشغيل.
- قاعدة البيانات الحالية مناسبة لمزرعة واحدة على جهاز محلي.
- يجب اختبار النسخ الاحتياطي والاسترجاع على بيانات تجريبية قبل الاستخدام الفعلي.
- لا تستخدم `git reset --hard` أو تحذف قاعدة البيانات لحل مشكلة تشغيل قبل أخذ نسخة احتياطية.
